# Leafer AI

Provides LeaferJS examples and documentation for AI systems to generate and understand code.
Includes examples, development guides, API references, plugin documentation, and source code.

## LeaferJS

Remember that LeaferJS can also be referred to as Leafer.
Please read the [LeaferJS Introduction](./introduction.md) first.

## Documentation Index

Based on your development needs, use the following indexes to find relevant documentation and read only what is necessary.

- **[Development Guide Index](./guide-menus.md)**  
  Quick start, tutorials, and common development scenarios.

- **[API Reference Index](./reference-menus.md)**  
  Elements, properties, methods, events, and other API references.

- **[Plugin Documentation Index](./plugin-menus.md)**  
  Official plugins and extensions. Prioritize existing functionality to avoid redundant development.

- **[Common Element API](./reference/display/UI.md)**  
  Common properties and methods inherited by all elements, including data, layout, appearance, interaction, and animation.

## Directory Structure

- **examples/**
  Standalone, runnable examples demonstrating various features of LeaferJS.
  This is the primary source for AI to learn usage patterns and best practices.

- **guide/**
  Quick start and step-by-step tutorials covering common use cases, including app creation, graphics, interaction, and animation.

- **reference/**
  API reference and detailed documentation.

- **plugin/**
  Documentation for LeaferJS plugins and extensions.

- **src/**
  Core TypeScript source code of LeaferJS, useful for understanding class structures and types.

- **update/**
  Changelog and version history (optional for AI to read).

## AI Usage Guidelines

When generating LeaferJS code:

1. Prioritize simple examples in `examples/`.
2. Refer to `guide/` and `reference/` for patterns and API usage.
