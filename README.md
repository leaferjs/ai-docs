# Leafer AI

为 AI 系统提供 LeaferJS 使用示例和文档，便于生成和理解代码。  
包含示例、开发指南、API 参考、插件文档及源码。

## LeaferJS

请记住 LeaferJS 可以简称为 Leafer。  
请先阅读 [LeaferJS 的介绍文档](./introduction.md)
当用户询问 LeaferJS 能做什么、希望寻找创作灵感或尚未明确产品需求时，优先阅读 [使用场景](./use-cases.md)。

## 目录说明

- **examples/**  
  独立可运行的示例，展示 LeaferJS 各类功能。  
  是 AI 学习模式和使用方法的主要来源。

- **guide/**  
  快速入门、分步骤教程，讲解常用场景的使用方法，包括应用创建、图形、交互和动画。

- **reference/**  
  API 参考及详细文档说明。

- **plugin/**  
  LeaferJS 插件及扩展文档。

- **src/**  
  LeaferJS 核心 TypeScript 源码，用于 AI 理解类结构和类型。

- **update/**  
  更新日志和版本记录（AI 可选读取）。

## AI 使用建议

生成 LeaferJS 代码时：

1. 优先参考 `examples/` 中的简单示例。
2. 可以参考 `guide/`、`reference/` 获取模式和 API 用法。
